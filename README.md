# PO List Browser

A Purchase Order List Browser application built from scratch for browsing and managing products in purchase orders.

## 🌐 Live Demo

Visit the deployed application: [https://po-list-browser.onrender.com](https://po-list-browser.onrender.com)

## 📋 Description

This is a built-from-scratch project for skills test in applying for a Frontend Developer position. The application provides an intuitive interface for browsing and adding products in a Purchase Order system.

## ✨ Features

- Browse purchase order lists
- Add products to purchase orders
- Interactive user interface
- Responsive design
- Real-time product management

## 🛠️ Technologies Used

- **React** (v18.2.0) - Frontend framework
- **React Router DOM** (v6.16.0) - Navigation and routing
- **React Icons** (v4.11.0) - Icon library
- **React Modal** (v3.16.1) - Modal dialogs
- **React Toastify** (v9.1.3) - Toast notifications
- **Boring Avatars** (v1.10.1) - Avatar generation

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/cacarl02/PO-List-Browser.git
cd PO-List-Browser
```

2. Install dependencies:
```bash
npm install
```

## 🚀 Usage

### Development Mode

Run the application in development mode:
```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will reload when you make changes.

### Build for Production

Create an optimized production build:
```bash
npm run build
```

### Run Tests

Launch the test runner in interactive watch mode:
```bash
npm test
```
